01 / О проекте

Маленькая команда. Большая история.

Это независимый короткометражный хоррор, который мы создаём небольшой командой. Наша цель — снять атмосферный фильм с сильной визуальной подачей, продуманным звуком и настоящим напряжением. Каждый вклад помогает приблизить съёмочный день.

ПАНЕЛЬ УПРАВЛЕНИЯ

Редактор сайта

Теперь можно редактировать тексты прямо на странице, загрузить изображение для постера, изменить ссылку и суммы сбора. Настройки репозитория и GitHub token запоминаются в этом браузере, чтобы не вводить их при каждой публикации. Храни токен только на личном устройстве и отзови его в GitHub, если устройство станет недоступно.

ПУБЛИКАЦИЯ В GITHUB — НАСТРОЙКИ

Заполни данные репозитория и вставь токен один раз. Они будут сохранены локально в этом браузере и восстановятся при следующем открытии редактора. Не используй эту функцию на чужом или общем компьютере.

Расширенное редактирование

Включи режим редактирования и меняй текст прямо на странице. Чтобы добавить картинку в любое место, загрузи её ниже, затем нажми на место страницы, где она должна появиться. Чтобы удалить картинку, нажми на неё на сайте и выбери удаление.

После загрузки нажми на место страницы, куда вставить изображение.
